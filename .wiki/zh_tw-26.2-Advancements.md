# 進度與成就 (26.2)

| 系统參數 | 状態 |
| :--- | :--- |
| **自定义進度 JSON** | **無**（架構設計上有意省略） |
| **功能范畴** | 纯粹玩法修饰 / 即時满足機制工具 |
| **原版進度兼容** | 100% 完美兼容原版所有故事与农牧進度 |

---

## 📌 缺省政策聲明

严格遵循本項目的**即時满足 (Instant Gratification, IG)** 設計理念与極致精简架構：
* Durability Multiplier **不封包含任何自定义進度 JSON 樹**。
* 本模組**不会**注册自定义触發器、條件准則或弹窗通知。

---

## 🌾 原版進度相容性

所有原版進度均可持续自然触發：
* 開采钻石矿石依然正常触發 **“钻石！”** (`minecraft:story/mine_diamond`)。
* 获得鞘翅滑翔依然正常触發 **“天空即為極限”** (`minecraft:end/elytra`)。
* 用盾牌格挡伤害依然正常触發 **“今天不行，谢谢”** (`minecraft:story/deflect_arrow`)。

由于物品耐久消耗完全在 `ItemStack.hurtAndBreak` 内部透明拦截，追踪工具使用、武器擊杀或護甲受損的進度判定不受任何干扰。
