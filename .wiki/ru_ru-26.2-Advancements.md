# Достижения и успехи (26.2)

| Системный параметр | Статус |
| :--- | :--- |
| **Пользовательские JSON достижений** | **Нет** (намеренно исключены архитектурой) |
| **Область действия** | Чистый модификатор геймплея / Утилита мгновенного удовлетворения |
| **Ванильные достижения** | 100% совместимость со всеми ванильными достижениями категорий «Приключения» и «Сельское хозяйство» |

---

## 📌 Декларация политики отсутствия компонентов

В строгом соответствии с философией проекта **Instant Gratification (IG)** и минимальным архитектурным следом:
* Durability Multiplier содержит **ноль пользовательских деревьев JSON достижений**.
* Мод **не** регистрирует пользовательские триггеры, критерии или всплывающие уведомления.

---

## 🌾 Совместимость с ванильными достижениями

Все ванильные достижения продолжают срабатывать естественным образом:
* Добыча алмазной руды активирует достижение **«Алмазы!»** (`minecraft:story/mine_diamond`).
* Полет на элитрах активирует достижение **«Небо — не предел»** (`minecraft:end/elytra`).
* Блокирование урона щитом активирует достижение **«Не сегодня, спасибо»** (`minecraft:story/deflect_arrow`).

Поскольку уменьшение прочности предметов происходит прозрачно внутри `ItemStack.hurtAndBreak`, достижения, отслеживающие использование инструментов, убийства оружием или износ брони, оцениваются без каких-либо помех.
