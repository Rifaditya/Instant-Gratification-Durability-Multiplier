# Changelog

All notable changes to Durability Multiplier for Minecraft 1.20.1 will be documented in this file.

## [1.0.0+1.20.1] - 2026-10-02

### Added
- Native port to Minecraft 1.20.1.
- Unified percentage-based durability scaling system (`ig:dm_percent_*`) via Dasik Library Dynamic GameRules.
- God Mode (`ig:dm_infinity_*`) for unbreakable tools, weapons, and armor.
- Single-Use Mode (`ig:dm_single_use_*`) for instant 1-hit breaking (Glass Mode).
- Dynamic modded item discovery and persistent sparse JSON overrides.
- Client-server network synchronization and customizable tooltips (`⟨...⟩`, `✦ UNBREAKABLE`, `✦ SINGLE-USE`).
